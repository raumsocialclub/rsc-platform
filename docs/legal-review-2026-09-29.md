### 국외 이전 확인 결과 (계약 자료 열람 불가 — 공식 문서·API 기준)

확인된 사실
- Supabase 프로젝트 리전 `ap-northeast-2`(서울). 문서(GDPR compliance → Data residency): 프로젝트의 주 Postgres·Auth·Storage 는 선택한 단일 리전에 호스팅. 조직 요금제 Free.
- Vercel 서버 함수 리전 `icn1`(서울, `vercel.json`).

문서로 확인되지 않은 것(국외 처리 가능성)
- Supabase 문서는 "백업, 로그, 외부로 내보낸 데이터, 서브프로세서가 데이터 상주·국외 이전 판단에 영향을 줄 수 있다"고 명시. 백업(S3)과 로그 인프라의 물리적 위치는 문서에서 특정되지 않음.
- Vercel 의 요청 로그·관측 데이터 저장 위치, 엣지 네트워크의 요청 경유 지점은 공개 문서 검색으로 특정하지 못함.
- 두 업체 모두 미국 법인이며 기술 지원·장애 대응 시 국외에서 조회할 가능성을 배제할 수 없음.

반영 방식
- 국내 저장·실행 사실을 그대로 적고, 백업·운영 로그·기술 지원 과정의 국외 보관·조회 가능성을 전제로 개인정보 보호법 제28조의8 제1항 제3호(계약 이행을 위한 처리위탁·보관, 방침 공개)에 따라 이전받는 자(Supabase, Inc. / Vercel, Inc.), 국가(미국), 항목, 시기·방법, 목적, 보유 기간, 거부 방법과 효과를 제9조에 공개.
- 확정을 위해 운영자가 할 일: Supabase DPA(supabase.com/legal/dpa)와 서브프로세서 목록, Vercel DPA(vercel.com/legal/dpa)와 서브프로세서 목록을 확인해 백업·로그 저장 국가를 특정하면 제9조의 "국외에서 보관되거나 조회될 수 있습니다" 문구를 확정 문구로 바꾼다. 법률 검토 시 이 조를 우선 검토 대상으로.

### 개정 절차 (법률 검토 후 변경 시)
1. 어드민 → 사이트 관리 → 약관 에서 해당 조 본문 수정 → 저장(이전 본문은 `site_content_history` 자동 보관).
2. 같은 문서의 "개정 이력" 조에 "YYYY년 M월 D일 시행 · 변경 요지" 한 줄 추가, "시행일" 필드 갱신.
3. 방침의 수집 항목·목적·보유 기간·국외 이전이 바뀌면 코드 `PRIVACY_CONSENT_VERSION` 도 새 시행일로 올린다(상담 동의 기록의 버전이 바뀜). 코드 기본값(`lib/legal/content.ts`)도 같은 내용으로 갱신해 두면 "기본값 복원" 시 되돌아가지 않는다.
4. 시행 7일 전(불리한 변경 30일 전) 공지.

## 6. Meta 픽셀 사용 반영 개정 (2026-10-01) — 스테이징 반영, 운영 배포 대기

운영자가 어드민에 메타 픽셀 ID 를 직접 입력해 광고 성과 측정이 시작됨. 제8조 제3항의 "외부 광고 측정 도구를 사용하지 않습니다" 문구가 사실과 달라져 개인정보 처리방침 기본값(`lib/legal/content.ts`)을 다음과 같이 개정.

| 조 | 변경 |
|---|---|
| 제2조 | 10호 신설: 광고 성과 측정(Meta 픽셀) 항목·목적·근거(정당한 이익). 상담 입력 정보는 전송하지 않음 명시 |
| 제3조 | 5호 신설: 브라우저에서 Meta 서버로 전송되는 수집 방법 |
| 제4조 | 9호 신설: 클럽 서버에 저장하지 않음, Meta 보관, 광고 식별 쿠키 최대 90일 |
| 제6조 | 행태정보 처리는 제8조 제3항·제9조 안내 문장 추가(제3자 제공 현황 "해당 없음"은 유지) |
| 제7조 | "광고 측정 도구 미사용" 문구 삭제, 제8조 제3항·제9조로 안내 |
| 제8조 | 3항 전면 교체: 처리업체, 수집 항목, 수집 방법·시점, 목적, 보유 기간, 거부·철회 방법(브라우저 쿠키 차단, Meta 광고 설정), 결합 금지 |
| 제9조 | Meta Platforms, Inc.(미국) 3호 추가(항목·시기·목적·기간), 거부 방법 문장 추가 |
| 부칙·개정 이력 | 개정 공고일·시행일 2026-10-01, 개정 이력 2줄째 추가 |

`PRIVACY_CONSENT_VERSION` 은 `2026-10-01` 유지(개정 시행일이 최초 시행일과 같고, 상담 신청 동의 범위(이름·휴대폰·상담 가능 시간·180일)는 변동 없음).

### 법률 검토 때 확정할 사항
1. **처리 근거**: 제2조 10호를 정당한 이익(제15조 제1항 제6호)으로 기재. 개인정보위 「온라인 맞춤형 광고 개인정보보호 가이드라인」상 제3자 행태정보 수집은 고지·거부 수단으로 운영 가능하다고 보았으나, 검토 결과 동의 방식(쿠키 배너)이 필요하면 배너 기능 추가 필요.
2. **국외 이전 근거**: 제9조 3호 Meta 를 제28조의8 제1항 제3호(처리위탁·보관 공개) 틀 안에 기재. Meta 가 자사 목적으로도 이용하는 점을 들어 제1호(동의)로 봐야 하는지 확인.
3. **제6조 제3자 제공**: Meta 픽셀을 제3자 제공으로 분류할지, 현행대로 행태정보(제8조)로 둘지 확인.
4. **사전 공지 기간**: 픽셀이 이미 켜져 있어 개정 공고와 시행을 같은 날(2026-10-01)로 처리. 7일 사전 공지를 지키려면 픽셀 ID 를 비워 두었다가 10월 8일 이후 다시 입력하는 방법이 있음(운영자 선택).

### 배포 시 할 일
- `legal.privacy` DB 저장본을 새 기본값으로 교체(`site_content_history` 에 이전 본문 보관) — 스크래치 `privacy-json.ts` 로 JSON 생성 후 update.
- 운영 주소 `/privacy` 에서 제8조 제3항 "광고 성과 측정 도구(Meta 픽셀)" 문구와 개정 이력 2줄 확인.
